# **App Name**: InstaVoice

## Core Features:

- UI Clone: Mimic the core Instagram UI for feed display, including image posts, stories, and profile pages.
- Voice Room Creation: Enable users to create voice rooms with optional password protection. The voice room should include a text-based chat feature.
- Voice Room Access: Allow users to join existing voice rooms. Display active speakers and chat messages in real-time.

## Style Guidelines:

- Use Instagram's color scheme: white background, black text, and blue accents for links and interactive elements.
- Maintain Instagram's default fonts for a consistent look and feel.
- Replicate Instagram's icon set for navigation, actions, and general UI elements.
- Follow Instagram's layout patterns for feed display, profile pages, and modal windows.
- Incorporate subtle animations for transitions and interactions, mirroring Instagram's user experience.
- Accent color: A muted purple (#A29BFE) for voice room UI elements to distinguish from standard Instagram features.
